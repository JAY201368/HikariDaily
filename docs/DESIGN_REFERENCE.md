# 当前视觉与交互基线

当前设计与验收只覆盖桌面布局，取消窄屏适配及核对要求（用户2026-11-13确认）。

产品是摄影师随身物件构成的阅读体验，顺序为概览、关键条件、拍摄建议。正式界面继承[离线原型](../prototype/index.html)，并按后续确认更新；原型保持原样，因此不是每处外观的最新快照。数据与产品范围见 [需求](../requirement.md)和[规格](../spec.md)。

## 连续动作与阅读

- 报纸完成两次独立折叠，再横置、缩放、对准真实袋口并下放；只有跨过袋口的部分被遮挡。桌面正常报纸完整置于顶栏与底部提示之间；超长正文自然读完后，在同一位置与尺寸交给折面，反向能恢复正文。
- 器材、手册与订阅单是背包中的同级物件，均由点击／键盘明确取用；页面继续下滑不再抽出或打开手册、订阅单。手册与订阅单入口均须可辨认、可点击。
- 按用户2026-10-29箭头图，手册塞入右后夹层，订阅单放在前沿空位，折好的日报向左让位。物件应有下半部被真实口袋前缘遮住的收纳关系，不能悬挂在包外或浮贴在皮革上。取消所有“取出”纸签／标签；封面、单据本身作为点击对象，hover／键盘focus沿现有器材方式发光。触摸直接点击，仍提供不可见的可访问名称。
- 手册和纸单先提清袋口，再移向上层阅读位置，手册封面翻开后留在纸块下面，稳定书脊、封壳、纸层与双面翻叶承托；关闭沿动作反向收回并恢复触发器焦点。普通／减少动效均采用点击取用，后者直接到可操作状态；无脚本保留全文线性阅读。
- 手册展开后不显示阅读层顶栏；点击书本与翻页控件之外的遮罩空白处即收回手册，Escape 同样可关闭。宽屏书本放大并下移，翻页控件紧随其后，减少下方空挡。
- 打开的书本以真实纸叶绕书脊翻动，不能用整体左右平移／淡入代替。箭头和悬浮纸页上的滚轮共用翻页；滚轮只作用于对应纸页，不全局接管；一次滚轮手势只翻一次，编辑、IME、拖拽、缩放及内部滚动各自保留。提供明确翻页控件。
- 书页是印刷实体，文字不在纸内滚动或展开；只排完整短段，不以截句、省略号、裁切或缩字塞入。长建议在物件外详情读取，无脚本输出保留全文。
- 订阅单独立收在背包，取消“手册末页发现／滚动抬起”依赖；取出展开仍沿用原单据内容与排版，输入保留，仍只提供既有订阅预览。
- 按用户2026-10-29订阅单截图要求，展开的纸单主体放大并在视口水平、垂直居中，隐藏阅读层顶栏；保留暖白纸张、红线表格和既有取出／收回动效。宽屏纸单宽度增至760px，长内容在阅读层自然滚动并保留纸外空白。验收：点击纸单外背景或按Escape可收回，点击纸内与操作表单不退出；打开后焦点落在地点输入框，关闭后回到入口，再打开保留输入和预览状态。

## 信息层次与可访问性

皮包段以器材本体与表盘承担入口；不在下面重复铺24个大按钮、完整字段和长说明。24小时明细用横向可比较的表格与逐时白话说明；“数据与出处”提供概览、分组逐时表和按需单项依据，保留来源时间、全部备注/备用值、太阳与风险依据。返回后保留阅读上下文，无脚本也能顺序读取完整事实。

皮包段移除“把天气带在身边。”标语及其标题占位，桌面背包与仪表整体上移、收紧顶部留白。所选小时提示、表盘、选时按钮、明细入口与逐时说明组成同一列；说明位于表盘控件下方，随文字自然增高，每段以表盘中轴居中，不保留左侧竖线。桌面动态与减少动效模式均按此布局验收。

关键文字与读数是真实 DOM，与器材图片分离。风险、未知和人工数据标识清楚。静态/减少动效保留全部内容、小时选择、题材与详情；装饰副本不可交互且对辅助阅读隐藏，过渡中不可见控件不获焦点。

素材出处见 [public/PROVENANCE](../public/PROVENANCE.md)和[原型出处](../prototype/assets/PROVENANCE.md)。生成过程和去除品牌不构成公开使用许可证明；未解决权利问题见 [CURRENT](CURRENT.md)。旧方案和纠正过程仅在[归档](archive/README.md)按需追溯。

## AI 摄影建议与账户

- 报纸拍摄建议与摄影手册由大模型结合 RAG 生成，使用同一事实与知识依据，SSR 不重复生成，账户或模型变化清除旧增强。现有信息分工、版面层次、完整短段和物件外详情保持。
- 首页顶栏提供账户与模型设置入口，支持服务地址、API Key 和兼容模型配置，清楚呈现连接与能力状态。
- 无有效配置或生成失败时使用规则建议，生成状态和失败原因可辨认。

## 拍摄计划本设计

背包左侧内仓用于新增拍摄计划本，沿用物件本体点击取用、提清袋口、展开和反向归位。正式应用接入此物件，已确认的视觉与交互以[独立设计方案](SHOOTING_PLANNER_DESIGN.md)和[桌面交互原型](design-prototypes/shooting-planner/index.html)承载本轮设计交付。

- 用户2026-11-14确认锁线胶装手账本、浅米白内页、留白为主的日式简约封面和桌面左右对开。
- 每次打开先显示目录，选中计划后书页翻动进入，选择回目录时反向翻回；栏目导航为贴在对应页、向外伸出的长条便签纸。
- 目录首对开左侧为扉页与图片，右侧为目录第1页、条目1–4。下个对开左侧为目录第2页、条目5–8，右侧为目录第3页、条目9–12，后续依物理纸页顺序延续。每页4条，页码与条目序号连续，扉页仅出现在首对开，末尾缺少的半页留白。搜索结果与回收夹遵循同样布局与分页。
- 用户填写的文本点哪块就在原处编辑该块，地点、题材、日程时间、标题、说明、准备事项、图片名与说明、资料页标题与正文分别独立。原型使用页面内单行或多行输入，普通文本空值保留可点击占位，日期与时间在原处使用浏览器对应输入控件。新建计划可使用表单。
- 出发准备常驻新增入口，点击事项文字编辑，独立勾选状态，每条提供删除入口。
- 贴图入口仅在参考样片栏目的末尾或空态出现。加页入口位于计划最后一张实际内容页的右下角，末页在左侧时直接填入同一对开的右页，末页在右侧时才翻到下一对开。快速连续操作会取消前一次装饰翻页，页面与最新操作一致。新增资料页提供就地删除入口，明确删除内容并可撤销，续页按所属资料页整组删除，撤销恢复内容与阅读位置。删除整份计划在目录条目中管理。
- 图片批注工具横排于图片右上方，包含画笔、箭头、文字、颜色、撤销、重做与清空。阅读、文字编辑和单图批注各自保留操作语义。
- 纸页及页内多行文字在阅读、编辑时均采用分页承载，页内无滚动区域。超出纸幅容量的正文完整接到下一页，输入区域按所属片段展开，测量计入实际输入控件与尾部换行。
- 计划文字按固定纸型连续分页，想法全部续页紧接首页，其后再排拍摄安排。栏目与资料标题仅在内容起始处出现，自动续页直接承接正文，页脚与导航保留所属内容名称。图片与短说明整体分页，长说明关联续页。手册的短段印刷与书外详情规则适用于摄影手册，计划本按其连续文档规则设计。
- 颜色、尺寸、栏目模板、保存与恢复等授权补全的设计选择及验收标准见完整方案。

## Authing 账户迁移（2026-11-16 已确认）

- 身份由 Authing 免费用户池的中文托管页提供，使用邮箱验证码；Better Auth 1.7.25 管理 OIDC 授权码、PKCE、身份令牌验证及数据库会话。旧账户、计划、图片和配置保留，旧登录凭证失效，外部身份仅按提供方与 subject 关联新的本地 UUID，不按邮箱合并。
- 顶栏“登录 / 注册”直接跳转，先保存本机计划、在编辑文字和批注草稿；返回原页面及参数。登录不会自动导入游客计划，导入和同步仍须主动选择。
- 登录后的账户设置沿用现有暖纸弹窗、字体、按钮、磨砂遮罩、关闭与焦点恢复；内容顺序为显示名和邮箱、计划同步、共用模型、账户管理、退出与注销。个人资料进入 Authing 个人中心，不再提供本地登录、注册、密码表单。保持原有桌面尺寸、布局和动效，不新增装饰动画。
- 注销区先说明将删除身份、模型配置、账户计划和图片，发送邮件验证码后输入验证码确认；处理中禁用重复操作，错误保留明确状态和重试入口。验证码错误或过期保持账户可用；验证成功后阻止私人访问并中止模型请求，显示注销进度，直到外部身份确认删除和本地事务清理均完成。完成后清除该账户浏览器缓存，游客本机计划保留。
- 桌面验收覆盖托管跳转及同源返回、纸张弹窗层次、加载和失败、验证码输入、注销重试、键盘操作与焦点恢复；安全验收覆盖回调、会话过期与撤销、旧凭证拒绝、账户隔离及两端删除恢复。真实免费应用的收信、登录退出注销及大陆访问为独立必验项。
