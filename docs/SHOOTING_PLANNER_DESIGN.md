# 拍摄计划本设计方案

2026-11-15 · 桌面设计、交互原型与正式接入

## 已确认的设计要求

- 拍摄计划本是背包左侧内仓中的同级物件，沿用封面取用、提清袋口、展开与反向归位的动作。
- 采用锁线胶装手账本，浅米白内页，日式简约封面，留白占主要面积。
- 桌面左右对开。每次打开计划本先翻开目录，选中计划后书页翻动到该计划。计划中的“回到目录”以反向翻页返回目录。
- 目录首对开左侧为扉页与图片，右侧为目录第1页。之后目录按物理纸页顺序延续，每页4条，页码与条目序号连续。扉页仅在首对开出现，末尾缺少的半页留白。搜索结果与回收夹使用同样的分页规则。
- 栏目导航使用贴在对应纸页上、向外伸出的长条形小便签纸。
- 用户填写的文本点哪块就在原处编辑该块，标题、地点、题材、日程时间、说明、准备事项、图片名与说明、资料页标题与正文分别独立。空值保留可点击占位，新建计划可使用表单。
- 出发准备常驻新增入口，事项文字点击编辑，勾选与文字编辑独立，每条提供删除入口。
- 贴图入口仅在参考样片栏目的末尾或空态出现。加页入口仅位于计划最后一张实际内容页的右下角。末页在左侧时新增资料页直接填入当前右页，末页在右侧时才翻到下一对开。资料页可就地删除并撤销，删除范围包含所属续页。整份计划在目录条目中管理删除。
- 图片批注工具横排于图片右上方，包含画笔、箭头、文字、颜色、撤销、重做与清空。
- 一份计划是可跨多页的结构化文档。固定纸张尺寸，真实分页，文字跨页接续，图片与独立批注随所属内容流动。
- 想法的全部续页紧接首页，拍摄安排从想法完整结束之后开始。
- 栏目与资料标题出现在内容起始处，自动续页直接承接正文。页脚与导航保留所属内容名称，正文区域依靠内容顺序自然衔接。
- 纸页及页内多行文本区域采用固定纸幅分页，正文超过可用区域时完整接到下一页。阅读和文字编辑均通过纸页承载内容，页内无滚动区域。
- 原需求中的新建、编辑、搜索、查看、删除、自动与手动分页、批注会话、自动保存与失败状态均进入完整方案。
- 当前设计与验收范围为桌面。用户授权由设计方案补全未指定的内容与交互细节。
- 阅读层背景与拍摄建议手册、订阅单页面一致，采用 `#302e27ba` 半透明遮罩与 `5px` 模糊；计划本封面和内页继续保持不透明纸张质感。
- 导入与同步入口归入账户管理的“拍摄计划”区域，计划本阅读页不显示该入口，也不显示摄影手册入口。
- 保存状态只在书本上方显示一次。未登录时显示“未登录，计划保存到本地”；阅读页不显示当前计划标题注解。
- 计划本各页面和背包入口不使用 slogan 或宣传式短句；保留事实标签、状态说明和直接操作文案。

## 方案补全与设计取舍

以下为本次授权补全的设计选择。封面采用灰米色细纹纸面，标题墨灰绿。内页采用轻纹理浅米白。每页逻辑尺寸为 480 × 680，左右对开为 960 × 680，视口变化时整体缩放。摄影模板由概况、拍摄安排、参考样片、准备、拍后记录组成。图片使用顺序排版与预设宽度，完整批注能力包括画笔、箭头、文字和框选。目录管理多份计划，每份计划拥有自己的页码。

每次打开先到目录，进入某份计划后恢复该计划上次阅读的内容位置。此规则按本轮确认执行。原需求中的小屏条目继续遵循项目当前桌面范围。

## 一、内容与信息架构

一本计划本包含目录与多份计划。每份计划包含结构化字段、可重复的拍摄条目和资料，纸页由排版生成。目录按拍摄日期排序，日期未定的计划集中显示在末尾。每条显示标题、日期、地点、页数与草稿／待拍／已拍状态，操作菜单提供重命名、复制与删除。

首对开左页为扉页，放本名、月份与一张参考照片，右页放搜索、目录第1页和新建入口。目录每张纸页容纳4条，页码按物理纸页连续计算，条目序号在当前列表中连续递增。

| 对开位置 | 左页 | 右页 |
| --- | --- | --- |
| 首对开 | 扉页与图片 | 目录第1页，条目1–4 |
| 下一对开 | 目录第2页，条目5–8 | 目录第3页，条目9–12 |
| 后续对开 | 目录第4页起，依次承接后续条目 | 接续左页的下一张目录页 |

扉页仅占首对开的左侧。每张目录页最多4条，末页条目不足4条时保留该页剩余留白，末尾缺少配对纸页时整张半页留白。搜索结果与回收夹使用同一纸页顺序、容量和连续编号规则。

搜索覆盖标题、字段文字、图片说明和文字批注，结果显示匹配片段和所属栏目。打开结果后定位到内容并短暂高亮。返回目录时恢复查询与原结果所在对开。图像文字和手写识别作为独立扩展能力。

### 摄影模板

| 栏目 | 字段与内容 | 排版方式 |
| --- | --- | --- |
| 概况 | 标题、拍摄日期、地点、题材、想法与画面意图 | 首页概况与想法，想法续页连续排完后进入拍摄安排 |
| 拍摄安排 | 可重复添加的时段、机位、拍摄对象、画面构想、准备动作 | 每条有稳定身份，可排序、复制、关联参考图 |
| 参考样片 | 图片、说明、独立批注、关联拍摄条目、来源备注 | 持续追加，按图组续页，贴图入口位于栏目末尾或空态 |
| 准备 | 器材、服装或道具、到场安排、可勾选事项 | 常驻新增入口，文字就地编辑，勾选独立，每条可删除 |
| 拍后记录 | 实际情况、完成画面、下次调整 | 自由段落，可关联图片 |

创建即获得一份草稿，允许逐步填写。日期和地点可留空，默认标题为“未命名拍摄计划”。示例计划“江岸的午后”对应上海外滩、2026年11月21日。示例内容带有清楚的原型标识。

| 项目 | 设计值与要求 |
| --- | --- |
| 封面 | 灰米色 `#D3CDBB`，细纸纹，约三分之二留白，左上小标题“拍摄计划本” |
| 内页 | 浅米白 `#F5F0E5`，薄而可辨的纸边，轻微纸纤维 |
| 正文 | 墨灰绿 `#343B34`，中文宋体，16px，约28px行高 |
| 控件 | 系统无衬线，12–14px，标签清晰，键盘焦点有独立轮廓 |
| 便签 | 麦黄 `#DCCB9B`、灰绿 `#BFC9B9`、藕灰 `#D4BFBA`。文字同时表达栏目 |
| 纸型 | 单页 480 × 680，对开 960 × 680，正文左右页边约44，顶部54、底部42 |
| 书脊 | 中央缓弧阴影、少量可见锁线、书帖层次。封壳从纸边露出4–7px |
| 就地操作 | 文字区域显示轻微悬停与焦点反馈，贴图入口融入参考样片末尾，加页入口贴近末张内容页右下角 |

封面、书脊和内页保持同一物体的连续形态。页面外缘圆角约4px，浅阴影承托纸张。拍摄参考图以纸质照片贴入，纸胶带只用于明确的图片固定关系。照片旋转角度计入排版占位。

整体缩放保留纸型、字号比例和内部换行结果。放大后的桌面阅读层支持移动视口。当前内容的操作入口、翻页按钮与保存状态仍可到达。底部居中显示当前对开页码与前后页按钮，目录与计划页面保持相同位置；缩略图入口展开纸页总览，选择后收起。目录的回收夹入口配有文件夹图标。

## 三、页面母版

| 母版 | 内容组织 |
| --- | --- |
| 目录首对开 | 左页扉页、本名、月份与参考照片，右页搜索、目录第1页的4条索引和新建入口 |
| 目录续对开 | 左页承接下一张目录页，右页再接下一页，每页4条，末尾缺少的半页留白。搜索结果与回收夹同样分页 |
| 计划首页 | 标题、日期地点与想法形成主层级，后续纸页先承接全部想法，再进入拍摄安排 |
| 文字续页 | 从页内正文起点直接接续前页内容，标题仅在内容起始处出现 |
| 参考样片页 | 一张通栏或两张并排，图片与短说明共同占位，栏目末尾或空态提供贴图入口 |
| 清单页 | 准备事项与勾选反馈，常驻新增入口，每条文字、勾选与删除独立，较长备注自然续页 |
| 独立资料页 | 用户命名，标题与正文独立就地编辑，允许文字和图片混排，空白时保留，删除时包含同组续页 |

每份计划从完整对开开始，页码从1计算。目录显示计划页数。栏目便签绑定栏目的首个内容锚点。便签从对应页的外侧伸出，按栏目在书页右侧错位排列，当前栏目便签略突出并加深文字。重排后便签随栏目首内容迁移。

## 四、取用、翻页与导航

1. 点击背包中露出的封面，手账先提清袋口，再移向阅读位置，封面绕书脊翻开到目录。
2. 点击目录条目，纸叶绕书脊翻向对应计划。跨多页跳转使用短促的连续翻叶，最终落到目标对开。
3. 点击“回到目录”反向翻回目录。计划内的便签与缩略图按目标方向翻动。
4. 点击阅读层书本以外的毛玻璃空白区域关闭封面并归位，恢复背包入口焦点。下次打开仍先显示目录。

相邻翻页约420ms，跨页导航约650ms，避免等待逐张经过全部页面。纸叶有正反面和动态阴影，翻动层中的装饰副本排除交互。快速连续操作时取消前一次装饰翻页，页面与最新操作保持一致。减少动效时直接切换到稳定终态。

阅读模式支持按钮和方向键翻页。滚轮只在纸面阅读状态处理，一次手势触发一次。文字编辑、选择、拖拽、缩放与原生滚动优先使用自己的手势。搜索和跳转记录内容锚点、文字偏移与视口偏移，重排后据此恢复位置。

## 五、三种编辑状态

| 状态 | 入口与主要控件 | 退出行为 |
| --- | --- | --- |
| 阅读 | 翻页、便签、目录、图片查看 | 可直接合本 |
| 文字编辑 | 点击文本块后，该块在原位置进入编辑，显示轻微边界，支持粘贴与连续输入 | 完成编辑后原处显示内容，草稿持续保存 |
| 单图批注 | 点击图片后选择“批注”。图片在独立编辑层放大，工具横排于图片右上方 | “完成”提交，“取消”恢复进入会话前版本 |

文字块本身承担编辑入口，键盘聚焦后可按 Enter 进入。标题、日期、地点、题材、想法、日程时间、日程标题与说明、准备事项、图片名与说明、资料页标题与正文分别绑定独立编辑目标。原型使用页面内独立的单行或多行输入，普通文本空值显示“填写地点”“添加说明”等可点击占位，日期与时间在原处使用浏览器对应输入控件。新建计划可以使用表单。

出发准备区域常驻“新增事项”入口，创建后在原位置填写。点击事项文字编辑该条，勾选框只处理完成状态，条目删除入口只移除该项并支持撤销。原型为旧数据中缺少身份标识的条目补充稳定标识，新增、删除和重排后继续对应原条目。

贴图仅在参考样片栏目末尾或空态发起。加页入口只出现于计划最后一张实际内容页的右下角。末张内容页位于左侧时，新增资料页直接填入当前对开的右侧并获得编辑焦点。末张内容页位于右侧时，翻到下一对开，新增资料页从左侧开始。新增资料页及其续页显示就地删除入口，操作前明确标题、正文与所属续页的删除范围，确认后删除整组，整次操作可撤销并回到恢复资料页所在对开。删除整份计划通过目录条目操作。

图片批注工具横向排列于图片右上方，包含画笔、箭头、文字、颜色、撤销、重做和清空。清空作用于当前图片会话，并可撤销。完整设计同时保留框选批注能力。文字批注进入搜索索引。手动分页符由文字编辑状态下的内容操作插入，并绑定当前位置后的内容。

Escape 依次关闭菜单、结束当前工具操作、处理批注会话，最后合本。有未提交批注时，提供完成或取消的明确选择。点击书外空白在阅读状态合本，编辑状态先结束当前局部操作。状态变化均保留回到原页的路径。

## 六、真实分页与连续书写

分页使用实际字体与图片尺寸测量内容高度，多行文字使用与页面输入区域一致的控件、宽度与排版规则测量，计入尾部换行。文字在统一文档模型中连续存储，跨页呈现为同一字段。想法的全部续页紧接首页，排完想法后再开始拍摄安排，栏目顺序随内容长度保持连续。标题至少与后续两行正文同页，段落尽量避免孤行。超长单词、链接和混排文字可换行，所有内容遵守固定可用区域。输入区域随所属片段完整展开，超出纸面容量的文字由续页承载。

中文输入法组词、跨页选区和拖拽期间，延后会打断操作的重排。输入确认后自动续页，恢复光标与选区。跨页复制、删除和粘贴按内容范围执行。一次撤销对应一次用户操作，其排版结果同时恢复。字体与图片加载完成后依据内容锚点恢复视口。

手动分页符绑定其后内容，编辑前文后仍表达“从新页开始”。自动空白尾页随内容收回。独立资料页具有稳定身份，空白时继续保留，其续页绑定同一内容组。资料页就地删除入口展示整组内容范围，确认后连同全部续页一并删除，并可整次撤销。“删除本页内容”用于选中的内容范围，操作前展示实际删除范围，确认后可整次撤销。

## 七、图片与批注

图片按内容顺序插入参考样片栏目，可关联拍摄条目，条目移动时关联资料随行。贴图入口位于栏目末尾或空态，支持文件选择，并在该区域接收粘贴和拖放。批量上传按选入顺序预留位置及尺寸，单张失败原位重试。图片可选通栏、半栏和保持比例的尺寸，用户可以裁剪和旋转。照片、批注与短说明作为整体分页。超大图片按比例适配，长说明续页直接接续说明正文，页脚标识所属图片，并保留查看原图与批注的入口。

原图资源与插入实例分离。每个实例保存自身批注、裁剪、旋转、尺寸和说明。重复插入同一原图可独立编辑。批注使用原图坐标，显示时统一映射，裁剪范围之外的批注继续保存。

进入批注建立独立会话与可恢复草稿，会话内撤销、重做只作用于当前图片。“完成”作为一次整体修改进入计划撤销记录，“取消”回到会话初始版本。意外刷新后可恢复草稿。提交失败保留编辑成果和重试入口。

## 八、保存、搜索与资料恢复

编辑先写入本机恢复草稿，再按稳定版本同步到所属账户。状态分别反映文字、批注和图片进度，使用“已保存到本机”“正在同步”“已同步”“还有2张图片上传中”“保存失败，重试”等具体反馈。合本后继续处理待完成写入，重新打开可查看失败项。

上传和保存重试复用内容身份。旧请求只确认对应版本。多个标签页修改同一计划时检测冲突，保留双方内容并提供选择。退出或切换账户时按所有者隔离草稿和资源，服务端检查计划、原图、实例与批注的归属。

删除计划后移入回收站，可恢复其内容与图片关联。永久删除明确展示范围。图片删除支持撤销，仍被其他实例引用的原图继续保留。模板升级使用版本号，旧计划按原模板打开。转换模板前列出字段映射并保留未映射内容。

搜索记录内容身份和文字区间。结果跳转、保存重开、翻页与缩放都用同一内容锚点定位，自动页码仅作显示。

## 九、天气引用与逻辑模型

报纸与手册建议可以作为引用收进计划，记录地点、目标日期时段、来源、获取时间和预报／天文计算／摄影推断类型。天气刷新单独显示变化，用户选择更新引用。未来日期可创建计划，数据覆盖不足时显示“暂无该日预报”。产品时间统一使用 `Asia/Shanghai`，保留数据缺失与来源分歧的具体事实。

| 对象 | 持有的信息 |
| --- | --- |
| 模板 | 版本、字段、顺序、填写与续页规则 |
| 计划文档 | 所有者、标题、日期、内容块、版本、删除状态 |
| 内容块 | 稳定身份、字段或条目关联、文字、分页意图 |
| 原图与图片实例 | 原始资源、独立展示变换、说明、批注与关联 |
| 批注会话 | 初始版本、当前草稿、操作历史、提交状态 |
| 排版结果 | 页尺寸、内容区间、内容到页的映射、页码，可重新计算 |

正式接入复用背包同级物件协调、账户身份和现有服务端数据边界，新增计划与私有图片持久存储。天气引用经过现有服务获取。模板、文档和排版分别维护，界面通过稳定身份处理编辑与导航。

### 正式接入约定

- 用户确认未登录可在本机使用，登录后由用户选择导入本机计划并开启同步。同步入口位于书本外的状态区，选择窗口展示本机计划数量和目标账户，提供导入并同步、仅开启账户同步、继续本机使用。
- 本机内容及图片保存在 IndexedDB，账户副本按所有者分区。自动保存先落本机，再按版本同步账户。账户切换取消旧请求并释放旧图片地址，天气刷新持续保留正在编辑的计划。
- 同步冲突保留两端版本，由用户选择合并保留副本。导入与网络重试具有幂等标识，重试成功后目录条目数量稳定。
- 图片通过独立私有存储接口管理，正式部署时选择存储适配方式。当前环境复用 PostgreSQL 保存原图及其类型、尺寸与所有者，图片获取验证账户归属，后续可替换对象存储适配器。
- 计划本阅读层由独立宿主持有，样式与事件在组件内隔离。背包封面随正式场景重新挂载，阅读层、文档与编辑状态保持稳定。
- 报纸与手册提供收进计划入口，用户选择已有计划或创建计划，引用保留内容快照、地点、日期、生成时间和来源。计划内可主动更新当前日期与地点相符的引用。
- 验收同时覆盖背包取放、物件互斥、本机离线保存、登录后的显式导入、账户隔离、图片上传及恢复、保存冲突、天气刷新中的编辑与图片批注，以及本文全部纸页规则。

## 正式接入的实现与核验

正式入口位于背包左内仓，未选择天气地点时也可通过“打开拍摄计划本”进入。阅读层独立持有文档，纸页内维持逐块输入、固定分页和图片会话。目录提供计划状态、重命名、复制、回收与恢复，资料页继续就地整组删除和撤销。原型目录与正式代码分别维护。

本机使用 IndexedDB，账户导入明确展示账户及本机数量，导入来源标识用于重复请求去重。同步先保留本机内容，再上传图片和提交文档。服务端核对会话所有者、基础版本、操作标识和图片归属。图片适配器当前使用 PostgreSQL，部署选型按已确认约定处理。

已用隔离账户检查本机创建、登录后继续本机使用、显式导入、重复导入数量、刷新恢复、账户与本机原稿独立、图片上传、文字和框选批注、撤销清空、旋转裁剪、批注搜索定位、加页与删除撤销，以及目录第五条落在后续左页。正式背包的封面取用和手册互斥切换已检查。纸页尺寸检查确认长文输入框高度与内容高度一致，正文处于纸页边界内。

定向自动检查覆盖本机存储、网络重试、迟到响应、多窗口合并、账户隔离、图像校验、版本冲突、手动分页、目录页序与中文组合事件。生产构建与类型检查通过。真实中文输入法候选窗口尚未纳入本次浏览器检查。
