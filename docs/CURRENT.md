## 当前目标

当前提供天气简报、复古物件交互、账户模型配置、公共知识检索与报纸／手册 AI 建议，以及正式接入背包的拍摄计划本。计划本沿用确认的锁线胶装、左右对开、固定纸幅、逐块就地编辑与纸便签导航。未登录在本机使用，登录后显式选择导入并开启账户同步。设计和验收条件见[拍摄计划本设计](SHOOTING_PLANNER_DESIGN.md)。

## 已有实现

拍摄计划本的正式组件由独立宿主承载，天气 HTML 更新时保留书本编辑状态。已接入本机文档和图片保存、账户导入、版本同步、冲突副本合并、私有图片接口、批注草稿、裁剪旋转与框选、手动分页、跨页键盘选择及复制粘贴、目录管理、回收恢复和天气快照收录。目录物理页序、连续长文、逐项准备清单、左末页直接加页及整组删除撤销沿用确认的交互。独立原型继续保留。

本机已应用迁移016、017。图片当前存于 PostgreSQL 私有表，正式部署环境确定后可替换独立图片适配器。账户内容及图片按所有者隔离，自动保存的重试身份与本机时钟用于处理迟到响应和多窗口修改。

核心网页已有地点选择、当天24小时、源适配与归一化、太阳与摄影规则、白话解释、物件交互、出处分组表和逐项依据。规则为 `photo-rules-v0.3`，晚霞空间模型为 `ecmwf-spatial-2026-10`，schema 为 `"2"`。

数据后端按单一职责拆分，并通过真实 LangGraph 执行：22节点简报主图串联请求校验、地点、取数与太阳、归一化、光线／风险／晚霞、三题材建议、解释、摘要、出处、数据状态和公开契约；7节点取数图独立编排四个来源及显式fixture分支；3节点地点搜索图独立校验查询、调用缓存provider并校验候选结果。SSR和简报API共用主图，地点API运行搜索图。纯领域模块、来源缓存决策和 I/O 生命周期分别保留独立入口，映射见[后端节点图](backend-graph.md)。

题材建议、解释、摘要已有类型化异步 `capabilities` 注入点，图 builder 可继续组合节点。公共主图继续使用确定性规则；独立的私有AI建议服务已接入用户模型与RAG，返回同一base的三题材短/全文并局部回退，已接入报纸、手册、详情、静态及无脚本出口；真实模型质量仍待验收。没有持久checkpointer或整份简报缓存，所有请求资源在状态之外管理。

晚霞分析在实际日落方向及左右25°采样本地和前方25–400km共16点，计算日落前后半小时的受光、遮挡及本地通透／降水限制。源缺失时返回未知，不沿用旧GFS单点评分。当前工程判断尚未经过独立的现场准确率验证，不能据此宣传量化提升。

默认源缓存关闭。现已提供 PostgreSQL 缓存适配器（迁移013）；本地私有 `.env` 显式使用该缓存。MET 已通过本机应用链路完成一次真实请求（HTTP 200），并在独立进程中命中同一持久记录。无数据库、迁移或有效身份时 MET 仍禁用；单源4秒／聚合6秒、原始获取时间、冷却及失败旧值限制保持不变。Vercel Runtime Cache 的真实平台待验范围未改变。

## 账户与 AI 摄影建议

- Authing 邮箱验证码与 Better Auth OIDC 数据库会话提供账户隔离；旧登录接口及旧凭证停用，旧账户数据保留，模型 Key 使用独立密钥环 AES-GCM 加密。
- 模型端点限定公共 HTTPS，DNS 与实际连接固定并禁止重定向，文本、图像与工具能力独立检测。
- 30条原创 CC BY 4.0 摄影知识支持显式导入、修订与撤回，检索先过滤适用条件再排序。
- AI 生成七类摄影叙述，规则事实与风险约束保留；SSR 共用已加载事实生成一次，客户端检查账户、配置、快照、代次及配对 hash。
- 当前迁移建立账户、独立身份会话、模型配置、限流、公共知识与可选来源缓存。旧数据库资料保留，清理数据需单独明确范围。
