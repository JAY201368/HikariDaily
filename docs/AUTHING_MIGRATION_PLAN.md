# 使用 Authing 替换登录鉴权，保留模型配置

保存日期：2026-11-16。状态：待实施，当前仅保存计划。

## 已确认的方向

- 采用 **Authing 免费版、邮箱验证码、中文托管登录页**，优先满足大陆访问。
- 使用全新账户；旧账户的模型配置、计划和图片保留，不自动关联新身份。
- 登录后的模型配置、能力检测和计划同步继续保留。
- 注销账户需再次验证邮箱，并同时删除 Authing 身份和逐光私人资料。
- 免费用户池目前每天可发送 50 封邮件，采用默认邮件服务。[官方额度说明](https://www.authing.cn/pricing/)

## 鉴权与数据改造

- Authing 负责身份认证；使用 **Better Auth 1.7.25** 的标准 OIDC 接入与会话管理，不自行实现验证码、密码或会话签发。[接入能力](https://better-auth.com/docs/plugins/generic-oauth)
- 新建逐光专用用户池和应用。通过授权码流程接入，开启 PKCE、身份令牌校验和同源返回地址限制；登录、退出均返回原页面。
- 为会话库增加独立数据表，沿用现有显式数据库迁移流程。外部身份关联本地账户 UUID，模型配置、计划、图片继续以该 UUID 隔离。
- 旧账户数据原样保留；旧登录接口停止提供服务，旧 `hikari_session` 不再获得访问权限，不按邮箱或用户名自动合并账户。
- 保留业务侧统一的 `requireAccount` 鉴权入口，更新首页 SSR、模型、AI 建议和计划接口的会话读取。游客查看天气不依赖认证服务或私人数据库。
- 保留模型接口、Key 加密、配置版本、端点校验和能力检测行为。身份服务凭证与模型加密密钥分别管理。

## 界面与接口

- 实现前，将已确认设计与验收条件写入当前规格和设计文档。
- 未登录点击顶栏“登录 / 注册”，直接进入 Authing 托管页；跳转前保存本机计划及批注草稿。返回后恢复原页面参数，计划仍需用户主动开启导入同步。
- 登录后保留现有暖纸弹窗、字体、按钮、遮罩、关闭方式和焦点恢复。内容依次为账户摘要、计划同步、共用模型、账户管理及退出／注销。
- 移除自建登录、注册和修改密码表单；身份资料管理进入 Authing 个人中心。加载、失败和处理中状态使用现有视觉语言。
- `GET /api/workspace/auth/session` 返回本地账户 ID、显示名和邮箱；模型与计划接口保持现有契约。
- 标准认证流程使用 `/api/auth/**`；注销保留业务接口，新增发送注销验证码的操作。邮箱和目标身份均由服务端会话确定。

## 完整注销流程

- 使用 Authing 的注销专用邮件验证码完成二次验证，不在本地生成或验证验证码。
- 验证成功后持久化注销进度，立即阻止该账户继续访问私人功能并中止在途模型请求。
- 使用官方 SDK 按已验证的身份删除并确认外部账户，再事务清理本地账户、模型配置、计划、图片及全部应用会话；完成后清除当前账户的浏览器缓存，保留游客本机计划。
- 两端操作可重复执行。失败显示明确状态并支持重试，提供恢复命令处理会话丢失后的未完成注销；只有两端完成后才显示成功。
