# 原型素材来源

两张素材沿用 HikariDaily 现有本地设计资产，逐字节复制。

| 原型素材 | 项目来源 | 用途 |
| --- | --- | --- |
| paper-texture.webp | public/textures/paper-texture.webp | 纸面细纹 |
| riverside-film.webp | public/textures/riverside-film.webp | 上海外滩江岸参考照片 |

原始出处、作者及授权链的已知状态记录于项目 public/PROVENANCE.md。两张素材当前用于设计评审，公开使用权仍待核实。原型中的日期、拍摄安排与说明属于示例内容。

手账封面、书壳、纸边、锁线、便签、控件与翻页由本原型的 HTML、CSS 和 JavaScript 绘制。中文字体使用设备已有宋体与无衬线字体栈。
