# 关键决策与经验

只保留当前仍有意义、难从代码直接恢复的理由。它们可随新证据和用户确认更新；历次实现及通过记录不自动成为后续任务规范。

| 决策 | 理由与适用边界 |
| --- | --- |
| 核心网页先于微信订阅 | 微信订阅仍后置，使用订阅号、地点及北京时间07:00/12:00目标。账户与模型配置服务于当前 AI 摄影建议。 |
| 原型保持独立，正式前端继承其物件体验 | 用户否定另起一套界面后的视觉漂移，要求直接移植原型再接真实 Briefing。正式代码可继续改进，但不能把离线样例或原型 globals 当正式数据边界。 |
| 印刷手册页内不滚动 | 页内滚动曾通过几何检查，却被用户明确否定为不符合实体逻辑。纸内放完整短段，长文在物件外详情读取；保留固定书脊和连续双面翻页。 |
| 真实视觉问题须验证相应可见行为 | 书本外框几何通过曾遗漏纸层显隐、文字跳变；复制素材也未保证构图一致。处理此类缺陷时选取能复现问题的检查，不把历史截图或几何断言当设计正确的充分证据。 |
| 解释在服务端生成，同一 Briefing 全站复用 | 保持报纸、逐时、器材、手册对事实、分档和时态的一致性，未来摘要也可复用。文字用白话、减少重复防御措辞；来源、缺失、时效和真实风险仍保留。 |
| 数据后端以单一职责模块映射真实 LangGraph 节点 | 地点搜索、简报编排、四源加载、纯规则、建议、解释、摘要和输出契约分别承担职责；模型能力已有类型化异步接口，当前运行仍是确定性规则。新增模型生成需保留事实与缺失语义并局部回退。现有映射见[后端节点图](backend-graph.md)，新增目标见规格第13节。 |
| AI 增强摄影建议 | 报纸与手册使用大模型和公共摄影知识，天气数值与风险继续由确定性规则生成。 |
| 开放注册与大陆直连作为运行目标 | 面向其他摄影用户提供注册与私有资料隔离；登录、资源、天气、模型及持久服务按中国大陆网络直接访问的条件选型，现有可选 Vercel 缓存不等于部署平台已锁定。 |
| AI 由用户自配兼容接口解锁 | 支持自行填写 base URL、API Key，接入 OpenAI 兼容接口；凭证和 AI 生成结果按用户隔离，平台不默认垫付。具体模型的图片与工具能力分别验证。 |
| 模型凭证按账户加密托管且可撤销 | 服务端加密保存 Key，用户可更新、删除。配置撤销使旧调用及迟到结果失效。 |
| 知识由项目整理，强调摄影见解 | 采用有明确来源及使用权限的知识材料与原创条目，重点支持题材、用光、构图与视角；《纽摄》等经典教材是参考候选，不代表已取得具体版本全文或图片入库授权。 |
| 阵风、冻雨及光照资格独立于高分 | 用户确认的 v0.2 调整：降低分量仍可能达到推荐分数，须另设资格门槛；几何地平线切片避免把日落后片段写成暖光。风光厚云只影响该题材，不机械降低人像/街拍结论。精确门槛见规格第6节。 |
| 气象缓存采用可替换的读写边界 | 需要保留旧快照、HTTP 验证头和冷却信息，不能只依赖不向 loader 暴露旧值的缓存封装。平台 SDK 隔离，默认关闭；配置或内存往返不等于跨实例验证。 |
| 浏览器检查使用独立构建目录 | 曾与已有开发服务争用目录锁。公开 `distDir` 与独立 tsconfig 让 `.next-e2e/` 隔离；不停止其他会话服务，数据模式仍需另外显式指定。 |
| 当前知识更新，已完成过程归档 | 按用户提供的[对话原则](https://chatgpt.com/share/6adeb81a-f3f8-83e8-8321-957969270229)：历史只按需检索；普通任务从相关代码开始，不继承旧任务卡的派发、通读和全套验收要求。小改动无需生成永久过程文档。 |

产品范围见 [需求](../requirement.md)，数值与接口契约见 [规格](../spec.md)，未解决事项见 [CURRENT](CURRENT.md)。需要追溯确认或失败细节时，再从[归档索引](archive/README.md)检索对应条目。
