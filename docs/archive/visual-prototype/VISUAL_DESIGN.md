# 逐光日刊 · 视觉设计原型 v1.1

> HikariDaily 的中文刊名现为「逐光日刊」；英文项目名与原型范围不变。
> 本轮交付：`prototype/index.html` 可交互离线原型；非核心网页实现、非实时天气、非真实订阅。
> 权威顺序：用户本轮偏好 → `requirement.md` → `spec.md`。参考稿只是视觉材料，不继承其数据规则与额外功能。

## 1. 取向：实物的可信度 × 编辑的秩序 × 动作的因果

你喜欢的不是「复古风网页」，而是**一套确实能被摄影师随身携带、使用与收纳的旧物**。实物负责情绪，排版负责判断；页面不讲无用的品牌故事，也不把气象数字伪装为现场测量。

| 维度 | 保留 | 舍弃 / 纠偏 |
| --- | --- | --- |
| GPT 器材 | 叶轮风温湿仪、腕上气压计、分体式日射读表、黄黑手持导航器；橡胶、磨损塑料、凹陷 LCD、接触阴影 | 工具箱、泡棉模切箱体、贴在仪器上的纸签；用小字反复解释原型身份 |
| GPT 动效 | 两个独立折痕、同一物件的运动、袋口遮挡、抽册及开合、顺滚逆滚连续 | 淡出一幕再淡入另一幕；新建一个长得不同的转场代理 |
| Claude 报纸 | 居中报头、细栏线、主副标题层级、窄栏逐时表、天文历、数据注解 | 无关广告、寻物转让、虚构「气象台消息」、晚霞百分比、超出当天范围的日期入口 |
| Claude 手册 | 黄色 / 朱红 / 墨黑印刷、章节编号、时间线、表格、胶片和器材说明 | 品牌胶卷、根据天气虚构 EV / 色温 / 快门、额外星空题材及机位承诺 |
| Claude 交互 | 点整个仪器展开说明、大读数与简短解读、报刊订阅单与盖章动作 | 扁平图标式器材、假二维码、虚假的「已订阅」、不符合基线的投递时刻 |

**拒绝四种替代品：**复古滤镜的数据卡片墙；作为背景墙的皮革图；为了好看而不可读的微缩报纸；割裂的滚动动画展览。

## 2. 视觉基调

### 色与材质

- 报纸底 `#eee6d4`，正文墨色 `#27251f`，朱砂强调 `#943b2d`。
- 皮革从栗棕 `#704b32` 过渡至深褐 `#33251e`；内衬暗橄榄 `#43463a`。
- 黄铜 `#a58a56` 只用于扣具、铆钉和边缘高光，不做金色 UI。
- 手册封面芥末黄 `#d7b33e`，朱红腰线 `#a23b2a`，内页暖白 `#f3eddd`。
- LCD 为灰绿 `#adb59a` 与深灰绿字符；数值是 DOM 文字，不烘焙在图片里。
- 纸纹低对比。报纸展开时就有两条浅旧折轴：不规则纤维损伤、宽窄变化、细碎斜纹、淡亮脊与阴影；折叠只沿旧轴自然加深。不要用四块矩形的边框伪装折痕，也不能在动效起点突然出现十字硬线。
- 皮革须有多尺度毛孔、包边厚度、鼓起的受光面、深色侧褶、缝线和边缘磨亮。接触阴影、袋内暗部与悬空阴影分层；不能只在平面轮廓上叠一个大阴影。

### 字体与版心

- 中文大标题与报纸正文使用本地宋体栈；小型工具界面用系统黑体，读数 / 时间用本地等宽字体。离线可读，不依赖字体 CDN。
- 宽屏报纸版心约 1120 × 700，可随可用高度适度缩放；若正文过小，转顺序阅读而不是继续缩小。
- 报头 64–76px，头条 30–38px，正文 15–17px，表格 13–14px，注解 12–13px（缩放后也需检查可读性）。
- 桌面主网格 12 栏；段落不超过约 4 行。每个区域只有一个主读数或主句。
- 保留印刷物中的空白、细线与小型栏目编号；不堆贴纸、印章、英语口号和重复状态条。

## 3. 第一幕：一份能快速读完的报纸

### 信息布局

1. **报头**：中央刊名与英文小字；左报耳「上海 · 城市参考点」，右报耳「日落 17:16 / 晚霞较高」。
2. **日期栏**：2026 年 10 月 21 日、北京时间、15:20 更新、固定演示；不把示例日期称为系统今天。
3. **头条**：「午后云隙见光，傍晚值得留一会儿」。副标题只解释一个原因与一个限制，不承诺必见晚霞。
4. **主栏（约 5/12）**：黑白网点城市照片，短导语，晚霞五级机会及主要依据。照片明确为氛围参考，不称为实况或预测画面。
5. **天气栏（约 2/12）**：14–22°C、晴转多云、风与降水摘要；三题材推荐用时间与一句理由，不用成功率或星数代替解释。
6. **逐时栏（约 2/12）**：展示有代表性的当天小时，时 / 温 / 云 / 雨；完整 24 小时在仪表小时带和逐时明细中可达。
7. **天文与空气栏（约 3/12）**：日出、日落、早晚蓝调及金调；参考 AQI 与 PM2.5、能见度分别列示。空气质量注明美国 EPA / CAMS，不贴中国「优良」标签。
8. **页脚**：预报 / 天文计算 / 产品推断的分类说明，来源入口，下一幕入口。

### 文案示范与限制

- 晚霞：`4 / 5 · 较高`，依据为日落小时中高云与低云、能见度、降水组合；固定样例采用规则可到达的四级条件，例如低云 50%、中云 50%、高云 20%、能见度 15km、降水 0mm，得分 70。
- 不确定性：「仅看本地预报条件；西向远方云场与建筑遮挡未验证」。不能复制 Claude 稿的远方光路已畅通断言。
- 手机取消四栏，改成报头 → 结论 → 天气 → 逐时 → 天文与空气；表格不缩成微型。

## 4. 第二幕：打开旧皮包，而不是工具箱

### 包的形态

改为 1990s–2000 年前后风格的**大容量旧皮革摄影背包**，不再使用窄长横向肩包。用饱满包体、可见侧幅厚度、软塌翻盖、两侧肩带、黄铜扣件、自然褶皱与深色衬里建立体积。容量要容纳多个上下错层收纳袋，而不是将旧肩包拉高或放大。**不用硬壳边框、箱盖铰链与模切泡棉。**

报纸插在前袋，黄色小册位于另一夹层；器材以两层或错落斜向布置在有深度的袋位，留呼吸空间，不在同一基线排队。袋口须真实遮挡物件下沿，但不能盖住主要读数。模型铭文与个人刻字是物件的一部分，不是贴上去的说明卡。

### 四件器材

| 原型 | 时代设计参照（仅交接文档 / 说明中作事实来源，不作可见商标） | 屏幕与解读 |
| --- | --- | --- |
| 叶轮式风温湿仪 | 1996 年起的 Kestrel 早期便携叶轮仪家族 | 平均风主读数，温度 / 湿度辅读数；阵风在旁侧编辑栏或点击说明内，非贴签 |
| 腕上气压计 | 1998 年 Suunto Vector 类户外腕表 | 海平面气压与趋势小图；气压变化不等同晴雨预报 |
| 分体式日射仪 | 1996 年 LI-COR LI-250 / LI-200SA 类读表与传感器 | 本轮保留实体类型与能量读数演示；单位 W/m²，绝不转换成 lux、EV 或曝光参数 |
| 黄黑手持导航器 | 1999 年初代 Garmin eTrex 类设备 | 所选地点坐标、日期、日出日落；不是用户 GPS 定位或卫星锁定 |

以上历史型号是参考稿提供的造型线索，本轮不声称重新完成了原厂史料核验。外形底图原为参考稿内无标识示意资产，当前使用 imagegen 细化实物质感，不冒称历史实物照片；在壳体上融入原创虚拟厂牌、型号、小型功能印字或主人刻字（例如 HIKARI FIELD / HG-96 / H.K.），与壳体角度、明暗和磨损一致，不使用真实品牌，不盖住读数。

气压与日射字段是**可逆的原型附加夹具**，尚不属于 `spec.md` 的生产接口；正式实现前须按变更流程确认数据源与字段，不扩张当前 API，不为视觉稿新增真实请求。

### 信息与交互

- 包上方是一行编辑标题：「把天气带在身边」。旁边清楚显示所选小时与「模型预报演示」。
- 用一只带链条、金属表圈、旧珐琅盘面的**24 小时怀表**替代下方小时长条与滑块。00 在上，顺时针 06 在右、12 在下、18 在左；直接点刻度或拖动指针，吸附到整点。盘面显示所选小时而非实时钟表，明确「拨针选时」。怀表应足够大以便操作，并与背包构成一组实物，不挤占仪器读数。
- 怀表支持鼠标、触摸、键盘方向键、Home/End，以及上一小时／下一小时按钮；触摸只在表盘捕获，页面其他区域保持竖滚。23 与 00 可互相跨越，缩放后的触点按实际表盘中心计算。
- 改变小时驱动 LCD 读数、短趋势、详情与注解，日落机会保持关联日落。不做传感器式随机抖数，直接同步夹具读数；温湿风等有单位。
- 四件仪器整件可点 / 可键盘进入，悬停仅轻微提起与阴影变化；没有悬停也能看懂。旁边用规整的两三列读数索引补足可读性，不在器材上贴说明纸。
- 详情为暖纸卡模态框：左放大原器材 / 右列当前值、对摄影意味着什么、单位口径、来源与限制；移动端上图下文。
- 云量 / 降水 / 能见度 / 空气质量呈现在一张**装在袋内的气象记录页**或编辑读数栏，不伪造古董仪器可以测全部指标。
- 提供 `缺失 / 旧数据 / 来源分歧` 演示切换。缺失显示「— / 暂无数据」，晚霞必要字段缺失则为「暂无法判断」，不是第一级。

## 5. 第三幕：从包内抽出的摄影手册

同一本黄封小册在第二幕已露出上缘与书名，第三幕沿袋口向上抽出，再移至阅读位置并绕书脊展开。封面与内页有厚度、叠页、订口暗部与微弧面；不要用一张平面黄色矩形替代书。

### 三个跨页 / 三个主题

各题材一跨页，桌面滚动翻页且提供前后页 / 题材直达；手机横向滑页，可随时竖向继续阅读。

| 跨页 | 左页 | 右页 |
| --- | --- | --- |
| 01 风光 | 今日风光判断；优先窗口；三步简短拍摄计划 | 太阳方位与地平线图解；分层云依据；低感彩负 / 反转片的条件与宽容度限制 |
| 02 人像 | 较柔光与金调窗口；脸部受光和侧逆光图解 | 风 / 温度限制；阴影替代方案；中感彩负与肤色风格参考 |
| 03 街拍 | 午后变化光与暮色窗口；按时间安排的行动线 | 长影 / 反光的条件性提示；中高感黑白负片；返程与防雨提醒 |

每页固定结构：小型页眉 → 编号与标题 → 一个主时间 → 2–3 条可执行建议 → 图解 / 胶片栏 → 限制 → 页码。胶片用通用类别，不出现商品名；不增加机位推荐、星空、数码曝光表。

所有窗口与报纸、仪表同一份示例事实一致。选中小时不重写全天手册；页眉可注明这是当天建议。

## 6. 尾声：一张报刊订阅单

借用纸质报刊投递登记单的细红线表格、蓝黑填写字与盖章反馈，不使用「中国邮政」标识或假官方背书。

订阅单是**手册页面之间夹着的一张完整红线纸单**：三题材阅读之后，继续滚动翻过额外一页，逐渐露出躺在书中的纸单，再抬离页面、拿出并放大至可填写尺寸。没有页上开缝、纸套或纸唇。翻页遮挡、接触阴影和取纸运动连续可逆；尾声文字在纸单落定过程中依次淡入并轻移，在正常流交接前已完整出现。手机同样要从正在阅读的手册抽出，不强制将用户切回某一题材。最后只有一份可操作表单，输入在回滚／重排中保留；静态或减少动态则顺序直接展示完整订阅单。

- 刊名：逐光日刊 · 摄影天气简报。
- 地点必须填写 / 选择，示例与当前地点一致。
- 投递时段：**晨刊 07:00 / 午刊 12:00，北京时间**。
- 渠道：微信订阅号；简报摘要 + 对应地点网页入口。
- 提交按钮：「预览订阅单」，反馈章：「演示登记」，同时说明「未创建订阅、不会发送消息」。
- 展示调整 / 停止的界面演示，不显示假的可扫二维码，不收集微信身份、不请求通知权限、不发起外部请求。
- 这只是第二阶段视觉设计，不使订阅成为首版工程依赖。

## 7. 动作分镜与不变量

宽屏一个 sticky 舞台，所有运动由原生滚动进度控制，可逆。当前实现总舞台 1250vh：保留原来的 900vh 阅读行程，在其后追加 250vh 抽单行程，另一个视口为 sticky 舞台高度。下表百分比均相对于原阅读行程，不因抽单追加而压缩读屏时间；紧凑布局先正常读完当前题材再追加抽单，具体实现见 `prototype/README.md`。

| 区间 | 动作 | 空间约束 |
| --- | --- | --- |
| 0–14% | 展开报纸，稳定阅读 | 第一次进入直接看到结论，不先播片头 |
| 14–22% | 右半沿竖折痕向左折 | 一次真正的 180° 局部翻折，有背面 |
| 22–30% | 下半沿横折痕向上折 | 与第一次折叠分开，四分之一面积 |
| 30–39% | 报纸向包前袋移动并插入 | 先悬空再接触；前袋口遮挡纸的下沿，不突然透明消失 |
| 39–57% | 皮包仪表稳定阅读 | 四件仪器、同一报纸一角、同一手册都在场 |
| 57–68% | 黄色手册从右内袋抽出 | 开始位置与第二幕一致；先脱离袋口再展开 |
| 68–75% | 手册翻开并落定 | 书脊固定，封面转动，不以缩放替代开书 |
| 75–83% | 风光跨页 | 可停留 |
| 83–91% | 翻到人像 | 有连续页片翻转，不能纯替换文字 |
| 91–100% | 翻到街拍 | 可回翻；纸单先在页间露边，稳定阅读之后进入追加的抽单区间 |
| 手册之后追加区间 | 订阅单从夹页抽出并落定 | 继承手册实际位置，页片遮挡逐渐解除，同一纸单到达可填写位置；反向还原 |

- 正文 DOM 与动画物件共享内容。用于折叠面片的不可交互副本须 `aria-hidden`、无 ID 重复、无可聚焦子控件；不在转场中造出第二个不同物件。
- 非阅读阶段不保留可聚焦的隐藏按钮。章节导航到稳定位置，不要求用户恰好滚到某一帧。
- 不拦截 wheel / touchmove；惯性只能平滑视觉进度，不能改写用户滚动位置。
- 窄屏先保证报纸和手册原生字号与顺序。过渡可使用同内容的装饰折叠副本，但它必须和阅读物件在交接处对齐并连续；默认保留入包 / 出包的空间叙事。小屏不能用整页缩小替代适配。
- 减少动态 / 手动「静态阅读」时三段按正常文档流展示，完整内容、小时切换、说明和题材仍可用，手机仍可横滑手册。

## 8. 本轮验收

1. 宽屏至少检查 1440×960，窄屏 390×844；再检查减少动态。
2. 报纸在首屏有结论与清楚的层级，没有无关广告、价格或口号。
3. 明确是宽裕、有体积和上下错层袋位的旧皮革摄影背包，不是窄长肩包或箱体；四件仪器保留高质感底图并加入原创虚拟铭文／定制刻字，不贴纸条。
4. 检查两次折叠中点、入袋中点、手册抽出中点；与稳定场景采用同一物件位置，反向也连续。
5. 用怀表点选／拖针／触摸／键盘选择 09:00 / 16:00 / 18:00，并验证 23↔00；读数和注解改变但报纸全天范围、手册全天建议与日落时段不改变。
6. 四件仪器点击和键盘可进入详情，Esc 退出，恢复焦点；模态框不溢屏。
7. 三题材内容不同、有理由与限制；桌面可滚动翻页，手机横滑，不锁竖滚。
8. 缺失不显示 0，旧数据有时间，分歧保留不同值；晚霞有五级说明，未知独立。
9. 订阅单从手册夹页连续抽出，正反方向与手机均无跳变；输入在回滚中保留。只接受 07:00 / 12:00，提交明确是演示登记而非开通成功。
10. 本地直接打开可用、无外部依赖；测试不能将夹具当成真实数据接入验证。
