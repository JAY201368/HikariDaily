# 单任务派发模板

你在仓库 `/Users/jay/Desktop/SE/课题/HikariDaily` 只执行下方一张完整任务卡。

1. 先读 AGENTS.md、requirement.md、spec.md、docs/DEVELOPMENT.md、docs/DESIGN_REFERENCE.md、ARCHITECTURE.md、TASKS.md、PROGRESS.md、DECISIONS.md 及范围内嵌套规则。检查 git 状态、依赖证据，先复述范围/排除项。
2. 配置：指定worker profile / 精确model / thinking / rationale由主agent注入。只报告可观察运行metadata，配置不等于有效thinking证据。
3. 你不是唯一工作者；保留他人改动和原型/引用资产。只改明确拥有文件，不递归委派、不调用本编排技能、不接受其他任务ID、不commit/push/deploy/发外部消息。
4. 缺依赖、范围/契约问题先报告主agent，不能自行扩接口或规则。公共契约先由主agent改架构和卡。
5. 跑卡中有意义的验证，保留失败/跳过。PROGRESS只在Current State追加待验收证据；如有非例行持久决策，向主agent建议DECISIONS条目。主agent拥有文档最终状态/验收勾选。
6. 最终报告：ID、配置及观察metadata、文件、行为、每验收项证据、精确命令/结果、环境/契约/迁移影响、风险/阻塞。完成后停止，仅可接本ID纠正。
