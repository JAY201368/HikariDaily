## 集成入口与行为

入口 [analyzePhotography](../../../../src/domain/photography/index.ts)：

```ts
analyzePhotography(
  day: NormalizedDay,
  solar: SolarEvents,
  location: Location,
  now: string | number, // 显式绝对时刻，不取系统时钟
): {
  rulesVersion: "photo-rules-v0.1";
  hours: Hour[];
  summary: Summary;
  sunsetOpportunity: Opportunity;
  advice: Record<Genre, GenreAdvice>;
}
```

供 T07 直接组装既有 Briefing：服务仍负责日期、来源加载／过期清理、星历、整体 state、warnings 和最终 schema 校验；本入口不网络访问、不读取 clock、不持久缓存、不改变输入，不返回内部评分。地点 ID／坐标不匹配会抛 RangeError；无效 now 拒绝。使用既有 [NormalizedDay](../../../../src/domain/normalization/index.ts) 的逐源 riskInputs、严格 primaryWeather 以及合并后指标。小时光照以小时中点计算；候选另以小时与蓝调／金调边界切片后在各片段中点计算，天气仍来自所属小时。

单独复用可从摄影目录导入 assessLight / assessLightAtPosition、assessHourRisks / assessSourceRisks、assessSunsetOpportunity；windows.ts 与 sunset.ts 的评分辅助仅为内部可重复计算与测试接口，不扩公开响应契约。中文内容为确定性模板，胶片为通用风格参考。
